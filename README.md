#   🌐 Frontend Development Module: Project Log

This repository documents the structured, assignment-driven progression through the core concepts of frontend web development.

## 🎯 Key Outcomes: A Chronological Timeline

This timeline maps the practical assignments and completed projects to the course's 7-lecture progression, illustrating the cumulative acquisition of skills.

### Lecture 1: Introduction to Web Development

Concepts Covered: Overview of frontend/backend, client–server model, web request flow, and tool setup.

Key Project/Outcome: Initial environment setup and understanding of the 3-Tier Architecture.

Associated Branch(es): intro-to-web-dev

### Lecture 2: HTML Fundamentals

Concepts Covered: Structure of an HTML document, headings, paragraphs, links, lists, images, and semantic elements.

Key Project/Outcome: Built a basic webpage; created a timetable using `<table>`.

Associated Branch(es): `html`

### Lecture 3: Page Elements and Embedding Content

Concepts Covered: Difference between block and inline elements; embedding media using iframes (videos, maps).

Key Project/Outcome: Created a webpage demonstrating block/inline layouts; embedded YouTube & Maps using` <iframe>`.

Associated Branch(es):` html-block-&inline-elements, html-iframes`

### Lecture 4: Introduction to CSS

Concepts Covered: Ways to add CSS (inline, internal, external), selectors, properties, values, and basic styling.

Key Project/Outcome: Applied basic styling; webpage with margins, padding, and positioning.

Associated Branch(es):` css`

### Lecture 5: Layout Techniques with Flexbox and Box Model

Concepts Covered: CSS box model, Flexbox fundamentals for aligning items, and Grid layout for two-dimensional designs.

Key Project/Outcome: Created a responsive layout using Flexbox; developed a Calculator layout using CSS Grid and gradients.

Associated Branch(es): `flex, css-model`

### Lecture 6: Advanced CSS Concepts

Concepts Covered: Pseudo-classes (:hover, :focus), transitions, transforms, and dimension units.

Key Project/Outcome: Implemented animations & tooltips; animated an element diagonally.

Associated Branch(es): `css-classes`

### Lecture 7: Responsive Design and Final Project

Concepts Covered: Principles of responsive web design, using media queries for mobile/desktop views, and Bootstrap CSS library.

Key Project/Outcome: Built a mobile-first responsive site; developed multiple sites including a header and a personal portfolio using Bootstrap.

Associated Branch(es): `responsive-css, BootStrap`
